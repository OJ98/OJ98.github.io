## Overview

ArgAnalysis35K is a comprehensive dataset for studying argumentation structures in natural language, with a focus on parliamentary debate contexts.

## Key Contributions

- 35,000 annotated argument examples
- Rich annotation scheme capturing argument components
- Multi-task learning framework for argument analysis
- Extensive evaluation on multiple NLP benchmarks

## Technical Details

The dataset includes annotations for:
- Claim identification
- Evidence extraction
- Argument relations
- Stance detection

Built with Python, PyTorch, and spaCy for preprocessing and analysis.
